CSS Fonts

Control font family, weight, style, and fallbacks. Example using Google Fonts:

<link href="https://fonts.googleapis.com/..." rel="stylesheet">
body { font-family: 'Inter', 'Roboto', system-ui, Arial, sans-serif; font-weight: 400; }

Tip: put the Google Fonts <link> in the document <head>.

!important

Forces higher priority: use sparingly — it makes CSS harder to maintain.

.btn { color: red !important; }

Simple priority (highest → lowest)

  1. Inline style with !important (e.g. <div style="...">)
  2. Author styles with !important (your external or internal CSS)
  3. Inline style (no !important)
  4. ID selectors (e.g. #header)
  5. Class, attribute, and pseudo-class selectors (e.g. .btn)
  6. Element/tag selectors (e.g. p, h1)
  7. Browser/user-agent default styles (lowest priority)

If two rules have the same specificity, the one that appears later in your CSS (source order) wins.

Tip: prefer increasing selector specificity or reorganizing styles instead of using !important.

Line-height

Controls spacing between lines. Use unitless values for scalability.

p { line-height: 1.6; }

Margin

External spacing between elements. Can be shorthand: margin: top right bottom left;

.card { margin: 1px 0; }

Padding

Inner spacing inside elements. Use to control touch targets and visual spacing.

.card { padding: 1px; }

Filter

Apply graphical effects: blur, brightness, contrast, grayscale.

img { filter: grayscale(50%) blur(1px); }

Overflow

Control content that exceeds its box: visible, hidden, scroll, auto.

.box { max-height: 100px; overflow: auto; }

Position

Values: static, relative, absolute, fixed, sticky.

.badge { position: absolute; top: 8px; right: 8px; }

Word-wrap / overflow-wrap

Keep long words from overflowing: overflow-wrap: break-word;

.content { overflow-wrap: break-word; }

Justify-content

Text Decoration

Underlines, overlines, line-through, and their styles/colors.

a { text-decoration: underline; text-decoration-color: #ff6b6b; }

Word and Letter Spacing

Control spacing between letters and words.

h1 { letter-spacing: 0.05em; word-spacing: 0.2em; }

CSS Variables (Custom Properties)

Define reusable values with --name and use var(--name).

:root { --brand: #6b73ff; } .btn { background: var(--brand); }
