What is CSS?

CSS (Cascading Style Sheets) is used to style HTML content — layout, colors, spacing, and more.

  • Separates presentation from structure
  • Makes pages responsive and attractive
  • Rules: selector { property: value; }

How to Add CSS

  1. Inline: <h1 style="color: red">Hello</h1>
  2. Internal: <style> ... </style> in <head>
  3. External: <link rel="stylesheet" href="styles.css"> (recommended)
<link rel="stylesheet" href="styles.css">

Basic Syntax

CSS rule example:

p { color: #333; margin: 0 0 1rem; }

Selectors

Common selectors:

  • Element: div
  • Class: .card
  • ID: #main
  • Descendant: nav a

Background Properties

Examples: background-color, background-image, background-size, background-position

Demo: gradient + image fallback
.demo-bg { background: linear-gradient(135deg,#6b73ff,#000dff); color: white; padding: 1rem; }

Border Properties

Use border-width, border-style, border-color, or shorthand border.

Border example
.demo-border { border: 3px dashed #cc6600; padding: 1rem; }

Border-radius

Round corners with border-radius

Rounded box
.demo-radius { border-radius: 12px; padding: 1rem; background:#f6f6f6; }

Display Property

Common values: block, inline, inline-block, flex, grid, none.

inline inline-block
block

Cursor Property

Change pointer when hovering: cursor: pointer, not-allowed, move, etc.

.demo-cursor { cursor: pointer; }

Float Property

Float moves elements left/right and text flows around them. Use with clearfix or prefer flex/grid today.

Example text flows around the floated image. Clearfix after the container to avoid collapsing.

.demo-float img { float: left; margin-right: 1rem; }
