# CSS Basics — Presentation

Files:

- `index.html` — the presentation HTML
- `styles.css` — presentation styles
- `script.js` — slide navigation (buttons + keyboard)

How to open (macOS, zsh):

1. Open Finder and double-click `index.html`, or from Terminal run:

```zsh
open index.html
```

2. Navigate slides with the Next/Prev buttons or the keyboard arrows.

Notes:
- This is a static presentation. No server required.
- Replace placeholder image URLs with local images if you prefer.
